## Overview

Swift Language Management System (SLMS) is a modular platform designed to simplify the management of language institutes.

The system provides a scalable backend architecture that supports institute management, courses, registrations, payments, attendance, grading, reporting, and other educational operations.

The project follows modern software engineering principles to ensure maintainability, scalability, and clean separation of concerns.
## Features

- Institute Management
- Student Management
- Teacher Management
- Course & Term Management
- Enrollment & Classification
- Tuition Management
- Attendance Tracking
- Report Cards
- Authentication & Authorization
- RESTful APIs
- Modular Architecture

## Architecture

The project follows Clean Architecture combined with CQRS and Domain-Driven Design principles.

Each layer has a single responsibility and depends only on inner layers.
